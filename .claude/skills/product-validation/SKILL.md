# تقييم واختيار المنتج

القاعدة: لا تحكم على المنتج من أداء متجر فيه مشكلة ثقة أو زيارات سيئة. افصل "المنتج سيء" عن "التنفيذ سيء". منتج جيد بتنفيذ سيء = 0 مبيعات أيضاً.

## 1. اقتصاديات الوحدة (أول فلتر — إذا فشل، المنتج مرفوض)
احسب لكل طلب:
- سعر البيع − (تكلفة المنتج + الشحن + التغليف + رسوم الدفع ~3% + نسبة الاسترجاع المتوقعة) = **هامش المساهمة قبل الإعلان**
- **Breakeven ROAS** = سعر البيع ÷ هامش المساهمة. فوق 2.5 = صعب جداً بإعلانات باردة. المثالي ≤ 2.
- هامش الربح الإجمالي المطلوب: ≥ 65–70% للتجميل، ≥ 60% لمعظم الفئات.
- متوسط قيمة الطلب (AOV): تحت $35 لازم حزم/upsell حتى تتحمل تكلفة إعلان (CPA الطبيعي على ميتا بأمريكا $20–$45 لمنتج جديد).
- قيمة الزبون على المدى (LTV): منتج استهلاكي بيخلص ويتجدد (makeup, skincare, supplements) أقوى بكثير من منتج يُشترى مرة.

## 2. بطاقة التقييم (كل بند من 1–5)
| المعيار | سؤال |
|---|---|
| ألم/رغبة قوية | هل في مشكلة حقيقية مزعجة أو رغبة عاطفية قوية؟ |
| وضوح خلال 3 ثواني | هل الفيديو يشرح المنتج بدون كلام؟ (wow factor / before-after) |
| طلب مثبت | بحث جوجل، تيك توك، أمازون Best Sellers، مراجعات المنافسين بالآلاف |
| تمايز ممكن | زاوية/جمهور/عرض ما بيقدمه المنافس الكبير |
| هامش وسعر | الشروط بالقسم 1 |
| تكرار شراء | بيخلص ويتجدد؟ |
| مخاطر تشغيل | مقاسات/درجات ألوان (= مرتجعات)، كسر، تنظيم (FDA/MoCRA للتجميل، مكملات)، شحن طويل |
| قابلية المحتوى | سهل يعمل UGC ومؤثرين؟ |
| إشباع السوق | إذا كل دروبشيبر بيعلن عليه بنفس الزاوية = حرب أسعار |

مجموع ≥ 34/45 = قوي. 27–33 = ممكن بزاوية ذكية. < 27 = غيّر.

## 3. مصادر البحث
- WebSearch / Similarweb: حجم الفئة، المنافسين، ترافيكهم.
- Meta Ad Library و TikTok Creative Center: مين بيعلن، من متى (إعلان شغال +3 شهور = مربح غالباً)، زواياهم.
- أمازون: Best Sellers + مراجعات 2–3 نجوم للمنافسين (= فرص التمايز).
- Reddit / مجموعات فيسبوك: لغة الزبون الحقيقية وشكاويه.

## 4. القرار
- **كمّل** إذا الاقتصاديات سليمة والبطاقة ≥ 27: المشكلة بالتنفيذ، أصلحه.
- **عدّل** (pivot جزئي): نفس المنتج، جمهور/زاوية/حزمة مختلفة.
- **غيّر**: اقتصاديات فاشلة أو بطاقة < 27. اختر بديل يستفيد من الأصول الموجودة (الدومين، العلامة، الجمهور، المحتوى).
- قبل أي استثمار كبير: **اختبار تحقق صغير** ($300–$600 إعلانات، 3–5 زوايا، 7–10 أيام) بعد إصلاح الثقة والتتبع. معيار النجاح: CTR > 1.2%، add-to-cart > 5%، CPA قريب من الهامش.

## 5. شكل التسليم
جدول البطاقة بالدرجات + حساب الهامش + القرار (كمّل/عدّل/غيّر) + إذا غيّر: 2–3 بدائل مع بطاقة لكل واحد. صرّح بأي رقم تقديري.
